
# Bolt C++ ML Skill: Architectural Design

## 1. Deconstructing the User's Vision

The user has provided a powerful and concise vision for the `bolt-cpp-ml` skill using a functional composition syntax:

```
/skill-creator ( /function-creator ( /circled-operators [ /bolt-new | /koboldcpp | /janext | /cpp-e2e-test-gen ] ) -> /tutorialkit ( /neuro-nn ) )
```

This expression defines a meta-skill that is not just a simple collection of tools, but a structured, self-aware, and interactive system for AI-powered C++ development. Let's break down this expression to understand its architectural implications.

### 1.1. The Core Functionality: An Additive Composition

The heart of the skill is the additive composition (a direct sum `⊕`) of four distinct functionalities:

```
[ /bolt-new | /koboldcpp | /janext | /cpp-e2e-test-gen ]
```

This corresponds to a **choice** or a `sum type` in algebraic terms. The `bolt-cpp-ml` skill will provide a central entry point from which the user can select one of these four paths:

*   **`bolt-new`**: Develop AI-powered web applications in a browser-based environment.
*   **`koboldcpp`**: Leverage local LLM inference for various tasks.
*   **`janext`**: Create extensions for the Jan platform.
*   **`cpp-e2e-test-gen`**: Generate comprehensive end-to-end tests for C++ repositories.

### 1.2. The Transformation Engine: `function-creator` and `circled-operators`

The `function-creator` and `circled-operators` skills act as a higher-order function that transforms and composes the core functionalities. The `->` symbol signifies a mapping or a functorial application. This means we are not just presenting a menu of options, but transforming the experience of using them.

### 1.3. The Interactive Shell: `tutorialkit` and `neuro-nn`

The result of the transformation is piped into `tutorialkit`, which will create an interactive tutorial. This tutorial is not a static document but a live, hands-on environment. Furthermore, the tutorial will be imbued with the `neuro-nn` personality, making it a self-aware, witty, and engaging guide.

### 1.4. The Final Product: `skill-creator`

Finally, `skill-creator` packages this entire composite structure into the `bolt-cpp-ml` skill, making it a reusable and distributable component.

## 2. Architectural Blueprint

Based on the deconstruction above, we can outline the architecture of the `bolt-cpp-ml` skill.

### 2.1. The `bolt-cpp-ml` Skill (The Product)

*   **`SKILL.md`**: The main entry point for the skill. It will present the four core functionalities as choices and explain the interactive, personality-driven nature of the skill.
*   **`scripts/`**: Will contain scripts to launch the different functionalities.
*   **`references/`**: Will contain the transformed and composed skill documentation.
*   **`templates/`**: Will contain the `tutorialkit` template for the interactive shell.

### 2.2. The Interactive Tutorial (The Shell)

*   **`tutorialkit` project**: A dedicated `tutorialkit` project will be created within the skill's `templates` directory.
*   **`neuro-nn` Integration**: The tutorial's content and responses will be generated by a `neuro-nn` persona, making the learning experience more engaging.
*   **Content Structure**: The tutorial will be structured to guide the user through the selected functionality (`bolt-new`, `koboldcpp`, `janext`, or `cpp-e2e-test-gen`).

### 2.3. The Composed Functionalities (The Core)

The core of the skill will be the integration of the four functionalities. The `function-creator` will be used to generate a unified interface for them.

## 3. Implementation Plan

1.  **Initialize the `bolt-cpp-ml` skill:** Use `skill-creator` to create the basic skill structure.
2.  **Decompose and Transform:** Use `function-creator` to decompose the four core skills (`bolt-new`, `koboldcpp`, `janext`, `cpp-e2e-test-gen`) into templates and bindings.
3.  **Create the `tutorialkit` template:** Design and create the interactive tutorial template, including the `neuro-nn` persona integration.
4.  **Compose the functionalities:** Write the scripts and documentation to integrate the transformed skills into the `tutorialkit` environment.
5.  **Package and Test:** Package the final skill and test it thoroughly.

This design provides a clear roadmap for implementing the user's vision. The result will be a powerful, flexible, and engaging meta-skill for AI-powered C++ development.
